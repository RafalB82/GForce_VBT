## GForce VBT — Aplikacje (Polski)

Aplikacja **Triki_G** to natywna aplikacja Flutter dla Androida, która łączy się z czujnikiem GForce VBT przez Bluetooth Low Energy i wyświetla w czasie rzeczywistym prędkość sztangi, liczbę powtórzeń i inne metryki VBT.

### Funkcje

- Live velocity (prędkość w czasie rzeczywistym)
- Detekcja powtórzeń (PhaseDetector + RepValidator)
- Podsumowanie serii (MCV, MPV, GPE, 1RM)
- Historia treningów z eksportem CSV
- Plan treningowy
- Statystyki i progresja
- Load-velocity regression (estymacja 1RM)

## GForce VBT — Applications (English)

**Triki_G** is a native Flutter Android application that connects to the GForce VBT sensor over Bluetooth Low Energy and displays real-time bar velocity, rep count, and other VBT metrics.

### Features

- Real-time velocity display
- Rep detection (PhaseDetector + RepValidator)
- Set summary (MCV, MPV, GPE, 1RM)
- Training history with CSV export
- Training plan
- Statistics and progression
- Load-velocity regression (1RM estimation)
