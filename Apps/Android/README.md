# GForce VBT — Android App

## Triki_G v0.1.0

### Installation

1. Download the APK from [app-release/triki-g-v0.1.0.apk](app-release/triki-g-v0.1.0.apk)
2. On your Android device, enable "Install from unknown sources"
3. Open the APK file and install
4. Enable Bluetooth and location permissions

### Requirements

- Android 8.0 (API 26) or newer
- Bluetooth 4.0 (BLE)
- GForce VBT sensor (Kapsel or Pro variant)
