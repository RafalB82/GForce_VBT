# Contributing

Thank you for your interest in GForce VBT!

## How to contribute

1. **Report bugs** — open an issue with a clear description, steps to reproduce, and expected vs actual behavior.
2. **Suggest improvements** — open an issue with the "enhancement" label.
3. **Submit changes** — fork the repository, create a feature branch, and open a pull request.

## Code style

- Firmware: follow the existing C code style in `triki/` (nRF5 SDK conventions).
- Apps: follow Dart/Flutter conventions with `dart format`.

## License

By contributing, you agree that your contributions will be licensed under the same license as the respective component:
- Firmware changes → GPL-3.0 + Commons Clause

- App changes → MIT

## Code of conduct

Be respectful, constructive, and inclusive.
